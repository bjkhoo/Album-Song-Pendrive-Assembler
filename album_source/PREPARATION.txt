========================================================
  PREPARATION GUIDE / 准备指南
  《稻、树林和风》原创专辑
  "The Paddy Fields, the Forests and the Wind"
========================================================

Before running album_copier.py, make sure all 10 MP3 files
are placed in this folder (album_source/) with these
EXACT file names:

  01 稻、树林和风.mp3
  02 Thankfulness.mp3
  03 满月.mp3
  04 我苦我乐我转转念.mp3
  05 含羞草的闪亮.mp3
  06 初心.mp3
  07 幸福答卷.mp3
  08 蝴蝶的呢喃.mp3
  09 拥抱无常.mp3
  10 六时·尔时.mp3

--------------------------------------------------------
  IMPORTANT NOTES / 重要提示
--------------------------------------------------------

1. File names MUST match EXACTLY
   (including spaces, Chinese characters, and punctuation)

2. The 2-digit prefix (01, 02, ..., 10) ensures correct
   playback order on car players and Bluetooth speakers.

3. Do NOT put files in subfolders — they must be placed
   directly in this album_source/ folder.

4. If your original files have different names, rename
   them to match the list above before running the script.

   For example, if your file is named:
     稻、树林和风.mp3
   Rename it to:
     01 稻、树林和风.mp3

5. Make sure all 10 files are present. The script will
   warn you if any files are missing.

--------------------------------------------------------
  QUICK CHECKLIST / 快速检查
--------------------------------------------------------

  [ ] All 10 MP3 files are in this folder
  [ ] File names match exactly (copy-paste from above)
  [ ] No subfolders — files are directly here
  [ ] album_copier.py is in the parent folder

  Ready? Run: python album_copier.py
